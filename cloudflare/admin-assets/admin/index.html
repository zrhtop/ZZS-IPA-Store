部署与使用说明

静态前端放在 GitHub Pages，IPA 可由 Pages 或 Releases 提供下载。

01 / PUBLISH

启用 GitHub Pages

打开仓库 Settings → Pages。Source 选 Deploy from a branch，Branch 选 main，Folder 选 /docs。保存并检查 Custom domain 为 repo.zrh.jp。

Pages 设置 ↗
02 / DNS

设置 Cloudflare DNS

创建 CNAME，名称为 repo，目标为 zrhtop.github.io。初次部署建议 DNS only（灰云），GitHub 可验证并颁发 HTTPS 证书。

03 / ACCESS

用户名与密码登录

后台需要通过 Cloudflare Worker 登录。首次登录必须修改默认密码；密码要求 10–12 位，且包含大写字母、小写字母和数字。

修改账号密码 ↗
04 / APPS

上架 IPA 和添加版本

20 MiB 以内的 IPA 可以在此页面上传；较大的 IPA 先上传到仓库 GitHub Releases，再复制 .ipa 文件的直链并输入准确文件大小。系统尝试读取 IPA 的 Info.plist，并自动识别应用信息。

创建 Release ↗
安全与兼容性提醒

管理后台已移至 Cloudflare Worker，未经登录不能读取后台文件或执行修改。登录页仍公开可见。不要上传敏感或无分发授权的 IPA。AltStore 会核对 IPA 实际权限与 source.json 中的 appPermissions，必须确保权限信息完整准确。
