如何使用管理后台

完全使用 GitHub Pages，不需要 Cloudflare Worker、服务器或数据库。

01 / GITHUB PAGES

保留现有 GitHub Pages 设置

仓库使用 main 分支的 /docs 文件夹发布，域名继续使用 repo.zrh.jp，无需修改 DNS 或新增服务器。

检查 Pages 设置 ↗
02 / LOCAL LOGIN

首次设置自己的密码

第一次输入用户名、10–12 位密码和一个 GitHub 访问令牌，之后在同一浏览器只需用户名和密码即可解锁。Token 使用 AES-256-GCM 加密后保存在浏览器。

03 / OTHER DEVICES

换手机或电脑

在已登录设备的账号设置中下载加密账户备份，在另一台设备导入并输入相同密码即可使用。也可用 GitHub Token 在新设备独立配置。

04 / IPA RELEASES

上传 IPA 和历史版本

20 MiB 以内的 IPA 可以直接上传到 GitHub 仓库；大型 IPA 请先上传到 GitHub Releases，再粘贴公开的 .ipa 下载链接。系统自动更新 AltStore 的 source.json。

创建 GitHub Release ↗
重要安全说明

GitHub Pages 无法在服务器端保护 /admin/ 目录。账号密码只能解锁本地加密的 GitHub Token，无法阻止别人查看公开的 HTML 和 JavaScript。GitHub 仍会校验每次仓库写入的 Token 权限。请只授予这个仓库 Contents: Read and write 的权限，并不要使用在聊天中公开过的密码。
