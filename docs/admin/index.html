使用指南

几分钟就能配置好这个个人 IPA 管理后台。

01

开启 GitHub Pages

在仓库 Settings → Pages → Build and deployment 中，选择 Deploy from a branch、main、/docs，然后 Save。

打开 Pages 设置 ↗
02

连接 GitHub 令牌

创建 Fine-grained personal access token，Repository access 只选择 ZZS-IPA-Store，Contents 授予 Read and write。点击右上角「连接 GitHub」，粘贴令牌。

创建 GitHub Token ↗
03

添加 IPA 或外部下载地址

本地 IPA 小于等于 20 MiB 时可直接上传；大型 IPA 请在 GitHub Releases 上传后粘贴下载链接。后台会尝试读取 Info.plist 中的应用名称、Bundle ID、版本和隐私权限。

04

通过 AltStore Classic 安装

进入 Sources，点击 + 并添加 https://repo.zrh.jp/source.json。发布更新时，新版本会自动排列在列表最前面。

安全与格式提醒

这个静态后台不是账号登录系统。任何人都可以打开 /admin/，但只有持有对该仓库具有 Contents 写入权限的 GitHub Token 才能修改源文件。Token 不会上传到 ZZS 自建服务器，也不会保存在浏览器 localStorage。公开 IPA 任何人都能下载，请只发布你有分发权的文件。

AltStore Classic 会比对 IPA 实际的 entitlements 和 Info.plist 隐私权限。解析器不能可靠读取应用签名中的所有 entitlement，请在上传前核对「高级权限」字段。
